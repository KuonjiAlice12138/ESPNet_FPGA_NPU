ESPNet INT8 NPU

卷积算子如何映射到 32x32 MAC 阵列

当前卷积核心把一个输出像素的输入 window 展平成 A[K]， 把一组输出通道的卷积核展平成 W[OC,K]， 再在 TM=32 输出通道 lane 和 TK=32 K-lane 的阵列上执行 psum[oc] += A[k] * W[oc,k]。

1. 顶层卷积数据流

Feature Buffer片上 feature memory，保存输入、中间层和输出 tile
Window Generator按输出行/列读取输入 window，并打包 K-lane
act_stream每个 word 是 32 个 INT8 activation lane
Weight Cache本层权重从片上 weight buffer 取出，按 OC/K tile 组织
32x32 MAC Array阵列单元做乘法，行末累加得到 psum
Post Processbias、requant、ReLU，INT32 转 INT8
Writeback写 row buffer，再写回 feature memory
权重是否在片上： 当前导出的 INT8 模型卷积权重总量约 108 KB，小于 WBUF_BYTES=128 KiB。 MODE_INIT 后卷积权重全部位于片上权重 buffer；执行某个卷积 UOP 时，再取出该层权重进入局部 cache。

3. Flatten、K tiling 与输出通道 tiling

2. 什么是 K lane，什么是 K tile

K lane 是阵列横向的一列，对应一个 k 值。 因为硬件横向宽度固定为 TK=32，所以一次送入阵列的 act_vec 最多包含 32 个 K lane。 K tile 就是把完整 K 维按 32 个一组切块： tile_id = floor(k / 32)，lane = k % 32。

若 K_total > 32，同一组输出通道会多次复用这 32 列阵列。 每个 K tile 产生一部分 dot-product，partial sum 会累加在同一条输出通道 lane 中。 当前综合结果中，K tile MAC loop 的 achieved II=1，因此阵列核心可以按 1 cycle / K tile 接收新的 act_vec。

level1: tile 0k0..k26 有效，lane 27..31 为 0 padding。
大 K 层: tile 1k32..k63 重新映射到 lane 0..31，并继续累加 psum。
输出通道 tile纵向 TM=32 对应 oc0..oc31；当前所有 conv 都只需 1 个 OC tile。
映射关系： 对任意一个 tile，阵列第 lane 列接收 A[tile*32 + lane]； 第 oc 行保存或读取 W[oc, tile*32 + lane]。 二者在交叉 cell 中相乘，同行 32 个 cell 的乘积被累加到该行的 psum[oc]。 因此横向是 K 维分块，纵向是输出通道并行。

4. 32x32 阵列中的乘法和累加

1. 权重填入 W[OC,K]
2. act_vec 广播到 32 行
3. 每个 cell 执行乘法
4. 每行累加输出 psum

阵列坐标：行是输出通道，列是 K-lane

以 level1_conv 为例

本层只有一个 K tile 和一个输出通道 tile。 所以一次阵列 pass 就能得到一个输出空间位置的 16 个有效通道。 本层权重填充只需约 36 cycles；对一般层可按 36 x K_tiles 估算该输出通道 tile 的权重装载开销。

for oc = 0..15:
  psum[oc] = Σ A[k] * W[oc,k], k=0..26

for oc = 16..31:
  psum[oc] = 0

对大通道层，公式不变，只是 k 分成多个 32-lane tile： 每个 tile 以 II=1 进入 MAC 阵列，多个 tile 的结果在同一条输出通道 lane 内持续累加。

psum[oc] = Σ_tile Σ_k_in_tile A[tile,k] * W[oc,tile,k]

5. 行级调度与写回边界

当前实现以输出行为基本流水粒度。行内 window 生成、权重流、阵列计算、post-process 可以重叠； 整行结果先进入 row buffer，随后再写回 feature memory。 这个边界是为了避免 feature memory 在同一个 DATAFLOW 区域里同时被读写而触发 HLS 合并/死锁风险。 阵列侧每个输出像素写出一个包含 32 个 INT32 lane 的 psum_vec_t，stream 写出动作可视为 1 cycle 级别；随后 post-process 以 UNROLL factor=4 对输出通道做 requant， 大约需要 ceil(out_c/4) cycles/pixel。

6. 与传统 2D 脉动阵列的数据流区别

传统 2D systolic：数据在 PE 网格中逐级移动

  • activation、weight、psum 通常按 skewed wavefront 在二维 PE 网格中传播。
  • PE 的邻接转发关系决定数据复用方式，适合大规模 GEMM 型规则数据流。
  • 若直接用于当前 ESPNet 多分支/小通道卷积，需要更复杂的 line buffer、psum buffer 和 back-pressure 控制。

当前 NPU：act_vec 广播，psum 在输出 lane 内累加

  • activation 不在 PE 网格中逐级转发，而是作为同一个 K-lane vector 广播到所有输出通道 lane。
  • 每条输出 lane 使用自己的权重向量，乘法发生在 lane 内的 32 个 K cell，累加发生在该 lane 的行累加器。
  • 空间位置 ow 主要顺序推进；并行性来自输出通道维度和 K-lane 点积，而不是二维空间波前。
关键区别： 传统 2D systolic 的核心是“数据在 PE 间移动并复用”；当前实现的核心是“一个输入向量广播，多个输出通道 lane 并行 dot-product”。 因此当前结构更准确地称为 weight-stationary / output-channel-parallel vector-MAC engine。
为什么这更适合当前 ESPNet： 当前目标网络不是少数几个大 GEMM 型卷积，而是由很多小输出通道、多分支、膨胀卷积和拼接/残差操作组成。 因此硬件更需要稳定处理“变化的 K 维 + 较小的输出通道数 + 频繁的片上 feature 重排”，而不是单纯追求一个大二维阵列在规则大矩阵上的峰值利用率。

结论： 这些数据说明当前网络的瓶颈不是“缺一个更大的二维 PE 网格”这么简单。 全部卷积的输出通道都不超过 28，14/26 个卷积的 out_c≤16，但 K 维从 27 到 1179 变化很大。 因此用输出通道 lane 固定、K 维分 tile、本地 psum 累加的数据流，可以把阵列接口统一成规则的 vector dot-product， 同时把 ESPNet 的小通道、多分支、dilation 和 concat/writeback 复杂性隔离在 window generator 与 UOP 调度层。
