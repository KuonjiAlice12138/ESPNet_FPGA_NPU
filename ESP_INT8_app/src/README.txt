ESP INT8 board app: H240-Resize, H512W1024 INT8 source test.
App tag: INT8-BOARD-20261025-P7-H240-RESIZE-H512-B2.

Platform: platform_h240_resize_1025
CPU/domain: psu_cortexa53_0 / standalone_psu_cortexa53_0.
The component, app.yaml and boot_h240.bif select this platform. The BSP includes
the generated src_mode Set/Get driver (AXI-Lite 0x44). The NPU and stage-counter
bases remain 0xA0000000 and 0xA0010000. Do not edit the generated driver or bypass
the HAL's missing-src_mode guard and mode readback check.

This experiment runs ONE full binary2 inference with src_mode=2. Native and
H256W512 cases are skipped, including their SD reads and summary rows.
INT8_APP_SOURCE_TEST_MODE in app_config.h selects the case; values 0/1/2 select
native/H256W512/H512W1024 respectively. Prefix, dual-model and val-set modes
are disabled. MODE_INIT still uses the original full PARAM v4 (75 UOPs,
16 EXEC including END). No model/QAT/PARAM change is required.

Input geometry: H512 x W1024 x C1, tightly packed signed INT8, no file header.
FPGA takes the central 512x512 square (x=256,y=0), then half-pixel nearest-neighbor
selection produces H240 x W240 x C1. This is NOT whole-wide-frame segmentation.
No RGB/gray conversion, input quantization, PNG decoding or interpolation
arithmetic is added. Raw Gray8 G512.BIN must NEVER be used as this INT8 source.
The encoder remains W8A8, with 30x30x2 logits and a 240x240 uint8 output mask.

Required SD data files (8.3 names):
P2G.BIN    143040 bytes, original model PARAM
I512Q.BIN  524288 bytes, high-resolution prequantized INT8 source
O512Q.BIN   57600 bytes, GENERATED by this run; absent before the test
Existing I2G.BIN/O2G.BIN and validation directories are not used or deleted.

Before copying to SD, validate RESIZEQ.json with input_resize_1023.py using
--validate-prequant-manifest. It checks dtype/layout/geometry, fixed qparams,
source/PARAM/model hashes and the integer-replay reference semantics.
App does not parse JSON. Signed INT8 and Gray8 cannot be distinguished by size.

Compare O512Q.BIN byte-for-byte against selected_int8_reference/M512.BIN.
Do NOT compare against the native input's golden_fullres_mask.bin. The deployed
M512/L512 are generated by PARAM integer replay, not the older research helper.
Labels: vehicles=0, valid background=1, ignored target=255. A valid histogram
does not establish correctness; the reference mask must match exactly.

DDR: input capacity 524288 bytes, output 57600 bytes, PARAM capacity 262144 bytes;
all buffers stay 64-byte aligned. Load/flush use the actual source byte count.
The hardware mode is written and read back before Start. On success the UART
prints binary2_h512w1024, source mode=2 bytes=524288, both stage/Conv dumps, and
one INPUT_SOURCE_SUMMARY row (mode=2, output=O512Q.BIN). Abort on mode mismatch,
timeout, ERROR-stage activity, invalid output labels or missing Conv profiling.

Timer: CNTPCT_EL0 / runtime CNTFRQ_EL0 (BSP 33333000 Hz), PL counters 100 MHz.
SD I/O, MODE_INIT, cache maintenance and UART dumps are outside inference timing.
FRAME_LOAD includes crop/resize/packing/input writes; the network runs afterward.
WIN/SA/POST counters overlap; do not sum them. POST bins include waits/requant/pack.
FRAME_LOAD<=24000 cycles and full inference<5000000 cycles are BOARD targets,
not results. HLS estimates FRAME_LOAD max=15377 cycles, sampler II=1.
